N Nova AI Studio

Confidențialitate

Ultima actualizare: 18 octombrie 2026.

Site-ul public

Site-ul este o pagină statică publicată prin GitHub Pages. Nu are formular de cont, chat, reclame sau analiză proprie. GitHub poate prelucra date tehnice de acces potrivit politicilor sale de confidențialitate.

Aplicația descărcată

Nova AI Studio rulează pe calculatorul utilizatorului. Proiectele se stochează în folderul local al aplicației. Conversațiile se păstrează în spațiul local al browserului.

Modelul AI

Aplicația trimite mesajele și contextul selectat către serverul Ollama local configurat pe dispozitiv. Codul nu este trimis de Nova către un serviciu AI găzduit de acest site.

Limitări

Nova nu oferă conturi online, sincronizare în cloud, telemetrie proprie, analiză de utilizare sau funcție de terminal. Utilizatorul decide ce model instalează și ce proiect deschide.
